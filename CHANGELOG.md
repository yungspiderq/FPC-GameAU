# Изменения

## 1.2.3 — 2026-11-23

- Пополнения Steam используют логин из поля оплаченного заказа FunPay и идут без дополнительного подтверждения в чате.
- Если в заказе нет корректного логина, бот запрашивает его у покупателя в чате.

## 1.2.2 — 2026-11-23

- Подробное описание оплаченного заказа помогает различать лоты с одинаковым кратким описанием.
- При неоднозначности уведомление показывает совпавшие ID лотов.

## 1.2.1 — 2026-11-22

- Автоцены Steam работают с номиналом ниже минимума одного пополнения GameAU, например 1 UAH за штуку.
- Расчёт использует котировку допустимого объёма и учитывает округление закупки при выставлении цены за одну штуку.

## 1.2.0 — 2026-11-22

- Настраиваемый полный автовозврат FunPay при подтверждённом отказе до закупки.
- Причины можно выбирать отдельно. По умолчанию автовозврат выключен.
- Статусы возврата в журнале и сверка с FunPay после сбоя без повторной отправки.
- Пополнение Steam по общему количеству из заказа FunPay и отдельный лимит суммы в валюте пополнения.

## 1.1.0 — 2026-11-17

- Автоматический расчёт и обновление цены FunPay по закупке GameAU и целевой чистой марже.
- Котировка вывода FunPay USDT TRC20 по умолчанию, ручной курс по валютам и расход USDT на пополнение GameAU.
- Расчёт себестоимости, прибыли и цен покупателей по платёжным методам.
- Общий переключатель автоцен, пауза на отдельном лоте и ручное изменение цены с подтверждением.

## 1.0.0 — 2026-11-14

- Первый релиз GameAU для FunPay Cardinal: восемь видов товаров API.
- Telegram-меню `/gameau`, пошаговая настройка, каталог с поиском, выбор изданий и регионов Steam.
- Подтверждение реквизитов покупателя; лимит списания `maxCharge` и резерв USD.
- Отключение привязанных лотов по настраиваемому балансу, сохранение запретов и ручное восстановление после пополнения.
- Тестовый режим; остановка обработки `/gameau_off`.
- Дисковый журнал, UUID идемпотентности, восстановление исходного запроса после таймаута.
- Проверка успешных статусов, числа и повторов кодов; ручная сверка неоднозначной отправки.
- Свежий список лотов без перезапуска.
- Автоматические тесты, проверка загрузчика Cardinal и схем запросов по OpenAPI 1.4.0.
